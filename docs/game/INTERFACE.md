# Interface

Este documento cobre as convenções de interface do jogo: escalas, responsividade e os comportamentos que os elementos da tela compartilham.

> Este documento cobre **a interface como um todo**. A tela do jogo e seus elementos estão em [Tela do Jogo](PLAY_SCREEN.md), e cada superfície — [mochila](BACKPACK.md), [armazenamento](STORAGE.md), [analisador de caçada](HUNT_ANALYZER.md) e as demais — tem documento próprio.

## Visão Geral

A interface do jogo é uma só, para desktop e celular. O conteúdo é o mesmo em qualquer tamanho de tela, e o que muda é o tamanho dos elementos dentro de um limite, em vez de uma versão separada para cada dispositivo.

Cada superfície tem as suas regras no documento dela, e aqui ficam as convenções que elas compartilham — escalas, comportamento em telas pequenas e os padrões de interface.

> Este documento está escrito só com a estrutura decidida e será preenchido com as convenções: escalas, responsividade, modais, popups e os padrões visuais.
