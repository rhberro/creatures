# Treinando como Criatura

Uma criatura não treina da mesma forma que um treinador — enquanto ele vai até uma academia ou biblioteca, ela **dedica todo o seu tempo a caçar**. Caçar é a única forma de uma criatura treinar.

## Diferenças em relação ao Treinador

|               | Criatura                    | Treinador                        |
| ------------- | --------------------------- | -------------------------------- |
| Onde treina   | Mundo aberto (PvE)          | Academia ou biblioteca           |
| Como progride | Caçando outras criaturas    | Treinando atributos próprios     |
| Offline       | N/A (precisa estar caçando) | Disponível apenas para "premium" |
