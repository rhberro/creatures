# Treinador

Enquanto você joga como treinador, o foco é estratégia e composição: você deve formar um time composto por diferentes criaturas de diferentes elementos, forte o suficiente para os diversos desafios que encontrar pela frente.

O treino do treinador é **direto nos seus próprios atributos** — você não evolui caçando. A caça existe, mas serve para ganhar experiência e fortalecer o time.

## Atributos do Treinador

Os atributos do treinador beneficiam as criaturas do seu time:

| Atributo     | Efeito no time                                |
| ------------ | --------------------------------------------- |
| Força        | Aumenta o dano físico das criaturas.          |
| Resistência  | Diminui o dano físico tomado pelas criaturas. |
| Inteligência | Aumenta o dano mágico das criaturas.          |
| Sabedoria    | Aumenta a resistência mágica das criaturas.   |

## Treinando

O treinador pode treinar em uma **academia** ou **biblioteca**, online ou offline. Detalhes em `@docs/game/trainers/TRAINING_AS_A_TRAINER.md`.

## Sistema de Elementos

As criaturas do time têm um ou dois elementos que definem vantagens e fraquezas em batalha. Veja `@docs/game/mechanics/ELEMENTS.md`.
